# 404NyanFound VPM

VCC / ALCOM package repository for mora's VRChat packages.

## Add to VCC or ALCOM
**Settings → Packages → Add Repository** and paste:

```
https://moralevi.github.io/vpm/index.json
```

Then open your project and add the package.

## Packages
- **NekoToon** (`com.nyanfound.nekotoon`): feature-rich toon shader for avatars. A fork of
  [lilToon](https://github.com/lilxyzw/lilToon) by lilxyzw (MIT); see the LICENSE and notices inside the package.

Release zips are attached to the [releases](https://github.com/moralevi/vpm/releases). The listing is rebuilt by
`.github/workflows/build-listing.yml` whenever a release is published.
